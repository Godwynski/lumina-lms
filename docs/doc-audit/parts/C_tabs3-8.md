Design of Software, System, Product, and/or Processes
In designing our software, system, and process, we utilized structured architectural and design approaches to
create a secure, efficient, and user-centered system. The system follows a layered architecture consisting of
the Presentation, Process/Logic, Database Client, and Database Core layers, ensuring clear separation of
responsibilities and maintainability. Database design applies Third Normal Form (3NF) to minimize
redundancy and maintain data integrity, while ACID transactions, row-level locking, advisory locks, and
database triggers support reliable and concurrent library operations. Security was incorporated through
authentication, role-based access control (RBAC), input validation using Zod, Row Level Security (RLS),
restricted database procedures, and comprehensive audit logging. The system also applies ISO/IEC 25010
quality attributes, focusing on functional suitability, performance efficiency, compatibility, usability, reliability,
security, maintainability, and portability. Integrating these architectural, database, security, and quality design
practices resulted in a robust, scalable, and user-friendly library management product.

TAB 6: Result and Discussion

Testing

In this part, the proponents present the testing activities conducted for Lumina: A Web-Based Library Book
Reservation, Borrowing, and Inventory Management System with QR-Based Scanning for STI College
Alabang. Testing focuses on verifying whether the developed modules and functions operate according to
their intended requirements. The system follows the Iterative Development method, where each feature is
tested after implementation to identify errors and necessary improvements. The testing includes Microsoft
O365 authentication, book searching and reservation, QR-based scanning, borrowing and returning,
attendance monitoring, inventory management, notifications, and administrative functions, with the results
used to improve the system in the next development cycle.

Description of Prototype

The prototype is a web-based library management system designed to provide students and library personnel
with a centralized platform for accessing and managing library services. It includes features such as book
searching and reservation, borrowing and returning, inventory management, attendance monitoring,
notifications, and user profile management. The system uses Next.js, TypeScript, Supabase, Tailwind CSS,
and HTML5-QRCode to support its web interface, database, and QR-based scanning functions. Overall, the
prototype is designed to improve the efficiency of library transactions, organize book records, and provide
convenient access to library services for students and library personnel.

Implementation Plan

The implementation of A Web-Based Library Book Reservation, Borrowing, and Inventory Management
System with QR-Based Scanning for STI College Alabang resulted in a centralized platform that supports
book searching, reservations, borrowing and returning, inventory management, and attendance monitoring.
Students can search and reserve books, view borrowing history and due dates, check attendance records,
receive notifications, and access their profiles. Library personnel can manage book records and transactions
using QR-based scanning, while administrators can manage inventory, borrowing logs, analytics, users,
settings, and audit logs. Overall, the implemented features provide an organized digital platform that supports
library operations, improves access to information, and reduces reliance on manual recording.

Implementation Results

The implementation of A Web-Based Library Book Reservation, Borrowing, and Inventory Management
System with QR-Based Scanning for STI College Alabang resulted in a functional system that integrates the
major library processes into one centralized web-based platform. The implemented modules allow students to
browse available books, reserve and borrow books, view borrowing history, and manage their profiles, while
administrators can manage book records, monitor inventory, process borrowing and returns, and manage
user transactions. The QR-based scanning feature was also implemented to support faster and more
accurate identification of books and borrowing transactions. Overall, the implementation results demonstrate
that the developed system successfully addresses the identified limitations of the existing manual processes
by providing a more organized, accessible, and efficient approach to library management.

TAB 8: Conclusion and Recommendation

CONCLUSION

The development and implementation of Lumina directly addresses the longstanding inefficiencies associated
with manual library operations at STI College Alabang. By replacing time-consuming paper logbooks and
manual shelf checks with a centralized, web-based platform, the project unifies book reservation, borrowing,
circulation, and inventory auditing into a cohesive digital ecosystem.

Through the integration of QR-based scanning technologies, Microsoft O365 enterprise authentication, and a
flexible iterative development methodology, Lumina ensures real-time data accuracy, minimizes
administrative wait times, and safeguards institutional records. The modular system design fosters an
intuitive, user-centric environment that simplifies daily tasks for administrators, librarians, student assistants,
and students alike. Ultimately, transitioning from traditional record-keeping to a modern, cloud-based digital
framework resolves immediate operational bottlenecks while laying a scalable, future-ready foundation. This
transformation directly supports STI College Alabang's broader commitment to academic excellence, data
integrity, and digital innovation in library management.

Recommendation The researchers conducted a complete evaluation of the system and identified advanced
areas for system expansion, specifically AI-Driven Predictive Shelf-Life and Condition Forecasting, Automated
Data-Anonymized CSV/JSON Audit Exporters for Accreditation, and Offline Queueing for Mobile QR
Scanning .

The proponents propose the following recommendation: 1.AI-Driven Predictive Shelf-Life and Condition
Forecasting The integration of a machine learning regression model within the management information
system (MIS) will optimize physical asset preservation. By tracking how often a specific physical book is
circulated, its age, and historical damage logs, the system can flag textbooks that are at high risk of structural
wear, allowing librarians to proactively plan for repairs, rebinding, or replacements before the material
becomes unusable.

2.Automated Data-Anonymized CSV/JSON Audit Exporters for Accreditation

Implementing an automated compliance module within the super-admin panel will greatly simplify institutional
evaluation processes. The system can generate encrypted, data-anonymized reports in both CSV and JSON
formats that demonstrate precise library utilization metrics, book-to-student ratios, and inventory turn rates
over specific academic years without compromising student privacy or data integrity controls.

3. Queueing for Mobile QR Scanning.

Give librarians and student assistants who perform inventories in remote areas of the library or have poor
internet connectivity offline access so they can continue scanning book QR codes; once a stable internet link
is established, the scanned data and transaction logs will be automatically synchronized with the Supabase
database.
