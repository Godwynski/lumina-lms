USERS GUIDE
This guide provides instructions for students and library personnel on how to navigate and efficiently use the
Lumina system. The system is designed to simplify library book reservation, borrowing, returning, inventory
management, and attendance monitoring through a centralized web-based platform.
Lumina uses Microsoft 365 authentication for secure user login and provides role-based access to features
intended for students and authorized library personnel.
System Requirements
A device with internet access such as a PC, laptop, or smartphone.
A valid STI Microsoft 365 account.
A compatible web browser such as Microsoft Edge, Google Chrome, or Mozilla Firefox.
An active internet connection.
1. Logging Into the System
1.1 Launch the System
Open a compatible web browser and navigate to the Lumina system website.
1.2 Microsoft 365 Login
On the login page, select Sign in with Microsoft 365.

1.3 Enter Credentials
Enter the user's STI Microsoft 365 account credentials and complete the required authentication process.
1.4 Role-Based Access
After successful login, the system displays the dashboard and features according to the user's assigned role.
2. User Roles and Features
A. Students
Students use Lumina to search for books, make reservations, monitor borrowed books, and view their library
information.
Key Features
View the Student Dashboard.
Search and browse available books.
View book details.
Reserve available books.
Report missing books.
View active borrowed books.
View reservations.
View borrowing history.
Access the digital library card.
Export the library card.
View frequently asked questions.
Manage profile information.
How To:
Search for a Book:
Navigate to the Catalog.
Enter the book title, author, or other available search information.
Select the desired book.
Review the book details and availability.
Reserve a Book:
Open the Catalog.
Select an available book.
Click Reserve.
Confirm the reservation.
View Active Borrowed Books:
Open the Student Dashboard.
Locate the Active Borrows section.
Review the currently borrowed books and their corresponding information.
View Borrowing History:
Navigate to Borrow History.
Review previously borrowed and returned books.

B. Library Personnel / Administrator
Library personnel are responsible for managing library resources, book circulation, users, inventory, and
system settings.
Key Features
Manage library books and assets.
Add and edit book records.
Monitor book statuses.
Generate and print QR codes.
Process book checkouts.
Process book returns.
Scan QR codes.
Manage reservations.
Monitor borrowing records.
Manage users.
Configure library policies.
Manage book categories and programs.
Manage announcements.

How To:
Add a Book:
Navigate to the Admin Dashboard.
Select Add Item.
Enter the required book information.
Save the book record.
Edit a Book:
Open the Admin Dashboard.
Select the desired book or asset.
Click Edit Asset.
Update the required information.
Save the changes.
Generate or Print a QR Code:
Open the book or asset record.
Select Print QR.
Review the generated QR code.
Print the QR code and attach it to the corresponding book.
3. Circulation Desk Functions
The Circulation Desk is used by authorized library personnel to process book borrowing and returning
transactions.

A. Checking Out a Book
Navigate to the Circulation Desk.
Select Checkout.
Launch the QR scanner.
Scan the student's library card or required identification.
Scan the QR code of the book.
Review the transaction details.
Select Process to complete the checkout.
B. Returning a Book
Navigate to the Circulation Desk.
Select Return.
Launch the QR scanner.
Scan the book's QR code.
Review the borrowing information.
Select Process to complete the return.
C. Resetting the Scanner
If a scanning transaction needs to be cleared, select Reset before starting a new transaction.
4. Managing Inventory
The inventory management functions allow authorized library personnel to monitor and maintain library book
records.

Key Functions
Add new library assets.
Edit existing asset information.
Monitor book status.
Assign book categories.
Generate QR codes.
Update inventory records.
How To:
Navigate to the Admin Dashboard.
Select the appropriate inventory function.
Search for the required book or asset.
Add or update the necessary information.
Save the changes.
5. Managing Reservations
Library personnel can monitor and manage student book reservations.
How To:
Access the appropriate reservation or circulation section.
Review the list of active reservations.
Check the student's reservation information.

Process the reservation according to the library policies.

9. Common Functions
A. Reporting a Missing Book
Students can report a book that cannot be located in the library.
Navigate to the Catalog.
Search for the missing book.
Open the book details.
Select Report Missing Book.
Submit the report.
B. Viewing the Library Card
Open the Student Dashboard.
Locate the Library Card section.
View the digital library card.
Select Export if a copy is needed.
C. Viewing FAQs
Open the Student Dashboard.
Navigate to FAQs.
Select the question related to the user's concern.
Review the provided information.
10. Updating Personal Information
Users can access their profile to review or update available personal information.
Navigate to Profile.
Review the displayed information.
Update the permitted information.
Save the changes.

11. Logging Out
To securely exit Lumina:
Click the user's profile icon.
Select Logout.
The system will end the current session.
Users should always log out after using Lumina on shared or public computers.
12. Troubleshooting and Support
Issue
Suggested Solution
Unable to log in
Check the Microsoft 365 account and internet connection.
Cannot access a feature
Check whether the feature is available for the user's assigned role.
Book cannot be reserved
Check the book's current availability and reservation status.
QR code cannot be scanned
Ensure the QR code is visible and properly positioned in front of the scanner.
Book information is incorrect
Report the issue to authorized library personnel.
Borrowing or returning transaction cannot be completed
Review the transaction details and try the process again.
System is not loading
Check the internet connection and refresh the browser.

For unresolved issues, users should contact the authorized library personnel or system administrator.

14. Important Reminders
Users must log in using their authorized Microsoft 365 account.
Students should verify book information before making a reservation.
Library personnel should verify transactions before processing checkouts and returns.
QR codes should correspond to the correct library assets.
Users should log out after completing their session.
Library policies configured in Lumina should be followed when borrowing, returning, and reserving books.
